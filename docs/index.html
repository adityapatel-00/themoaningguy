A deeply unnecessary desktop companion

Give your laptop feelings it never asked for.

The Moaning Guy is a gloriously unserious app that listens for slap-like impulses through a microphone or supported accelerometer, then fires off absurd sound effects. It also reacts to port shenanigans like charging, USB, display, network, and dock changes.

What this nonsense does

Slap detection

Accelerometer when fancy, microphone when not

Supported devices can use motion-sensor detection for sharper slap detection. Everyone else gets microphone mode, because modern problems demand modern nonsense.

Port events

Charging, USB, HDMI, Ethernet, and dock drama

Assign sound bundles to connect and removal events for whatever port categories your OS decides to reveal today. Very polite hardware chaos.

Sound packs

Import your own audio packs

Organize files into bundles, preview them, shuffle through them, and trigger different packs from the tray like you're programming a tiny cursed jukebox.
